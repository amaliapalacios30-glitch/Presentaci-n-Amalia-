02 · Fundamento

Programar reglas ≠ aprender de ejemplos

Automatización clásica

SI el monto supera un umbral, ENTONCES marcar alerta. La regla fue escrita explícitamente.

Machine Learning

El sistema ajusta un modelo a partir de ejemplos para estimar patrones y generalizar a casos nuevos.

La pregunta clave: ¿quién define la regla: una persona explícitamente o un proceso de entrenamiento?

04 · Métodos

Tres maneras de aprender

Supervisado

Aprende con ejemplos etiquetados.

Ejemplo: correo «spam» / «no spam».

No supervisado

Busca estructuras sin etiquetas objetivo.

Ejemplo: agrupar clientes por patrones.

Por refuerzo

Aprende mediante señales de recompensa y consecuencias.

Ejemplo: agente que mejora una estrategia en simulación.
05 · Arquitectura

Una red neuronal no es un cerebro

Entradas

Datos codificados: píxeles, palabras, números.

Capas

Operaciones con pesos ajustables y funciones no lineales.

Salida

Predicción, categoría o representación.

Aprender es ajustar los pesos para reducir errores definidos por una función de pérdida.

06 · Profundidad

¿Qué cambia con el Deep Learning?

Machine Learning

Amplia familia de técnicas que aprenden patrones de datos.

Deep Learning

Subconjunto de ML que utiliza redes neuronales con múltiples capas de procesamiento.

Más capas no siempre significa mejores resultados. Importan datos, arquitectura, cómputo y evaluación.

10 · Modelos de lenguaje

¿Cómo funciona un LLM?

Un modelo de lenguaje grande aprende patrones estadísticos en datos de entrenamiento y utiliza su contexto para predecir tokens y producir secuencias.

Token

Unidad de texto procesada por el modelo; no coincide siempre con una palabra.

Contexto

Información disponible durante la interacción.

Limitación

Una respuesta fluida no garantiza que sea correcta.

12 · Laboratorio práctico

Ahora sí: entrena tu modelo

Experimento en Teachable Machine

  1. Abre Teachable Machine.
  2. Selecciona Image Project y dos clases.
  3. Recoge al menos 20 imágenes distintas por clase.
  4. Entrena y prueba con ejemplos nuevos.
  5. Cambia el fondo y observa errores.

¿Qué debes descubrir?

¿Qué ocurre si el fondo es igual en todas las imágenes? ¿Qué pasa cuando cambia la iluminación? ¿El modelo aprendió el objeto o una pista accidental?

Si no se permite usar cámara, la docente comparte pantalla o se emplean imágenes permitidas.
